# wishlist

## clock
live time display near the greeting. pairs naturally with the time-based salutation already in place.

## pinned links
a row of icon-only (favicon) links above the search bar for the 4–5 sites opened every day. separate from categorized bookmarks — less friction than scanning categories.

## keyboard hint
a subtle visible hint for the `/` shortcut, shown only until used once, then hidden permanently.

## task manager
a panel showing tasks from an external service. candidates:

- **todoist** — REST API, no OAuth required for personal use (API token), good free tier
- **ticktick** — clean API but OAuth only
- **google tasks** — OAuth only, tightly integrated with google calendar

todoist is the simplest to integrate (single API token, no OAuth dance). the panel could show today's tasks only, with the ability to check them off and add new ones without leaving the tab.
